# Stage 2: ImageGen visual workflow

## 1. Create three overview directions

Generate A, B, and C from the same locked outline. Each direction must be a coherent presentation system, not a collection of unrelated mockups.

Each system must define:

- layout character and editorial rhythm;
- Chinese and English type hierarchy;
- primary, secondary, neutral, and alert colors;
- background treatment and whitespace;
- chart, icon, card, divider, footer, and page-number styles;
- image or scientific-illustration strategy;
- information density and visual center of gravity.

The three directions must differ structurally in layout, title treatment, chart language, imagery, background, density, and visual emphasis. A color swap alone is not a valid variant.

Generate one overview image for each direction. Use at most five columns and enough rows to show the exact slide count. Every thumbnail must remain 16:9, display its page number, and preserve the locked order. Do not add title cards or extra pages to the grid.

Thumbnail body copy may be abbreviated only for legibility; titles, key figures, chart relationships, conclusions, and page functions must remain unchanged.

## 2. Gate 2A: visual direction

Present A, B, and C together for comparison. Record the selected direction and any explicitly approved hybrid adjustments. Once confirmed, treat its visual system as the only design authority.

## 3. Generate individual slide visuals

Generate slides sequentially from page 1 through the final page, one independent image per call/output:

- full-frame 16:9 landscape;
- high resolution suitable for editable reconstruction;
- no montage, contact sheet, crop enlargement, watermark, or extra page;
- same typography character, colors, margins, modules, chart language, icons, footer, and folio system as the selected overview;
- composition and hierarchy stable enough to reproduce with PowerPoint objects.

Use the locked outline for exact text and data. If ImageGen renders garbled text, preserve the intended visual geometry but flag the text for native reconstruction rather than accepting it as content.

Generate the complete set without stopping for approval after each slide. Internally review and selectively regenerate only defective pages while keeping the rest of the system unchanged.

## 4. Gate 2B: full visual set

Before presenting the full set, verify:

- exact page count, numbering, and order;
- no duplicates or missing slides;
- correct key numbers, dose order, units, and chart direction;
- no content-role changes from the outline;
- no invented logo, brand, person, packaging, product UI, citation, or claim;
- no obvious gibberish in titles or prominent labels;
- consistent system across all pages.

Request one confirmation for the complete set. Record the locked image files and invalidate any earlier PPTX if the images later change.
