# Stage 1: Evidence and outline

## 1. Inspect and classify sources

Classify every input as primary literature, review, guideline, approved product information, regulatory material, company material, extracted text, or visual reference. Record the classification and exact path or URL in the manifest.

For PDFs, use extracted text for search but verify these items against the original document:

- negative signs, decimal points, percentages, confidence intervals, P values, units, dose order, sample sizes, and timepoints;
- table columns, figure legends, footnotes, special characters, and superscripts;
- whether a statement is a result, author interpretation, hypothesis, subgroup analysis, or cross-study comparison.

When external evidence is permitted, add only material that improves accuracy or fills a defined gap. Cite the exact authoritative source. For current guidelines or product information, verify the version online.

## 2. Set slide count and density

Derive slide count from the requested duration, audience, evidence volume, and desired density. If duration or audience would materially change the deck and cannot be inferred, ask before locking the outline.

Use one global density with optional per-slide overrides:

| Density | Default content per slide | Typical use |
|---|---|---|
| Concise | One conclusion, 2–3 points, one primary visual | Short external talk |
| Standard | One conclusion, 3–5 points, 1–2 evidence modules | Default academic report |
| Detailed | Additional methods, statistics, qualifiers, or subgroup evidence | Training or defense |

Apply density changes before locking the outline. Do not silently delete content later because a visual is crowded.

## 3. Build the outline table

Use exactly these columns:

| 页码 | 中英文标题 | 页面任务 | 核心结论 | 正文要点 | 关键数据/证据 | 图表/视觉形式 | 来源定位 | 证据边界 | 内容密度 |
|---|---|---|---|---|---|---|---|---|---|

For each row:

- assign one clear communication purpose and one dominant takeaway;
- specify actual chart type or diagram structure rather than saying only “data chart”;
- include exact values and units needed on the slide;
- identify the source page, table, figure, section, label, or URL;
- state material caveats such as mechanistic hypothesis, post hoc analysis, historical control, nonconcurrent comparison, or unsupported causal inference;
- note whether an illustration must be scientific, photographic, diagrammatic, or unnecessary.

Use a coherent academic sequence appropriate to the source. Literature decks commonly progress through background, question, design, methods, results, safety, interpretation, limitations, and outlook, but do not force headings that the material does not support.

## 4. Gate 1

After presenting the table, ask the user to confirm:

- total slides and order;
- titles, takeaways, and density;
- data, units, and evidence boundaries;
- chart and illustration assignments;
- permitted external sources.

Do not generate overview images yet. On confirmation, save the locked outline version and update the manifest.
